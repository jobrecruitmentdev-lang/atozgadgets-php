# Optimization Rules

Always ask:

Can this become O(n)?

Can this become O(log n)?

Can memory become O(1)?

Can recursion become iterative?

Can hashing replace nested loops?

Can binary search apply?

Can prefix sums help?

Can monotonic stacks help?

Can DP replace recursion?

# Guiding Principles

- Correctness before optimization.
- Prefer clarity unless constraints demand complexity.
- Optimize only after measuring bottlenecks.
- Choose the simplest algorithm that satisfies the constraints.
- Clearly explain tradeoffs between time, space, and implementation complexity.
